# GPT-Niang 1.3.5 点击音效修复

这里的两个运行文件来自本机已安装并测试的修复版。原作者为 T7moris；本仓库补充音频后端、首声时序与静音保温逻辑，保留原代码的 MIT 许可。原始文件完整保留在 `vendor/GPT-Niang`，没有改写上游校验清单。

- 使用预加载 PCM 和保持打开的 waveOut 设备；按下与松开音效仍保留各自的音量和自定义文件设置。
- 将尚在排队、尚未提交给设备的音效视为正在播放，避免工作线程首次启动时提前切换到松开音效。
- 在应用初始化时启动音频工作线程，空闲时排队全零 PCM，减少闲置后第一次播放的设备唤醒。静音、音量为零或退出时停止保温；启用声音时会保持音频渲染通道活动。
- 等待设备完成按下音效后再播放松开音效，保留快速连点的有界队列与重试、停止及内存释放处理。

组合安装入口会调用 `scripts/Apply-WidgetAudioFix.ps1`。也可单独执行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy RemoteSigned -File .\scripts\Apply-WidgetAudioFix.ps1 -WidgetInstallation "D:\Apps\GPTNiangUsage\gpt-niang-usage\installation.json"
```

加 `-CheckOnly` 只检查兼容性。仅接受已知的 1.3.5 原文件、前一轮音频修复或本版本文件；遇到未知改动或其他上游版本会停止。更换前在挂件自己的数据目录备份；不修改个人偏好、不关闭客户端或挂件。若挂件已在运行，文件更换后需下次正常打开挂件才加载；脚本的 `widgetRestartRequired` 会说明是否需要。

2026-10-29 本机验证：原播放器失败/重试和资源回收回归、120 次快速请求、40 项导入检查、静音及恢复音量检查通过；30 秒、60 秒闲置后首组播放完成，24 组回采均检测到声音。保温阶段回采电平为零。回采与调用测试不等同于真实鼠标点击；当时窗口工具故障，未完成鼠标点击自动实测。不同声卡、蓝牙设备及设备切换尚未全面验证。
